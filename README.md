# Proteus

An AI system for universities and colleges to navigate the AI era and remain relevant.

## Overview
Proteus is an institutional governance, scenario modeling, and strategic decision platform designed for higher education leaders, faculty, staff, and students.

### Features
- **Executive Governance & Institutional Profiles**: Campus telemetry, risk scoring, strategic AI adoption roadmaps.
- **Scenario Simulation Engine**: Model fiscal, academic integrity, workforce, and curriculum impacts across institutional archetypes.
- **Evidence Ledger & Staging**: Verifiable audit records, claims assessment, and accreditation compliance workflows.
- **Stakeholder Impact Analysis**: Dedicated views for leadership, faculty, administrative staff, and students.
- **Role-Based Access Control (RBAC)**: Fine-grained permissions, academic/administrative sign-offs, and multi-tenant isolation.
- **Firebase Persistent Storage & Firestore Rules**: Scalable cloud database backing with security rules.

## Tech Stack
- **Frontend**: React 18, TypeScript, Tailwind CSS, Lucide Icons
- **Backend / API**: Express, Node.js
- **Database & Auth**: Firebase Firestore & Firebase Auth
